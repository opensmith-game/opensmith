# Third-party notices

OpenSmith builds on the open-source projects below. Their licences apply to their code; the
full texts come with each package (`app/node_modules`, `~/.cargo/registry`, the Python
environment).

| Component | Licence | Use |
|---|---|---|
| [Tauri](https://tauri.app) and its plugins | MIT or Apache-2.0 | desktop shell |
| [three.js](https://threejs.org) | MIT | note highway and stage (3D) |
| [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch), [Teko](https://fonts.google.com/specimen/Teko), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (via Fontsource) | SIL Open Font License 1.1 | interface fonts |

The MPL-2.0 crates are used unmodified; their source is on [crates.io](https://crates.io).

## Installed on the player's Mac on the first import

The song converter (`pipeline-ingest`) is not bundled with its dependencies: on the first
import, `uv` downloads them from PyPI onto the player's Mac.

| Component | Licence | Use |
|---|---|---|
| [Demucs](https://github.com/facebookresearch/demucs) (`htdemucs_6s` model, downloaded on first use) | MIT | stem separation |
| [Basic Pitch](https://github.com/spotify/basic-pitch) (model included) | Apache-2.0 | guitar transcription |
| [PyTorch](https://pytorch.org) | BSD-3-Clause | runs Demucs |
| [librosa](https://librosa.org) | ISC | onsets, beat tracking |
| NumPy, SciPy, scikit-learn, soundfile | BSD | signal processing, audio files |
| [PyGuitarPro](https://github.com/Perlence/PyGuitarPro) | LGPL-3.0 | Guitar Pro import |
| [PyYAML](https://pyyaml.org) | MIT | feedpak import (manifests) |
| python-soxr, lameenc | LGPL-2.1+ / LGPL-3.0 | resampling, MP3 (via Demucs) |
| jsonschema, mir_eval, pretty_midi, julius, einops | MIT | chart validation, transcription tooling |
| certifi, tqdm | MPL-2.0 | downloads |

madmom is **not** used: its pretrained models are licensed CC BY-NC-SA 4.0. Beats come from
librosa and OpenSmith's own code.

## Tools the player installs

[uv](https://github.com/astral-sh/uv) (MIT or Apache-2.0), [FFmpeg](https://ffmpeg.org)
(LGPL-2.1+ / GPL depending on the build). OpenSmith runs them as separate programs and does
not distribute them.
